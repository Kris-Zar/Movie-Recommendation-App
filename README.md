# 🎬 Movie Recommendation System

An ML-powered Movie Recommendation System that helps users discover movies based on their preferences and movie similarities through an interactive **Streamlit dashboard**.

## ✨ Features

- 🎥 **Movie Recommendations** — Discover movies based on similarity.
- 🔎 **Movie Search** — Explore movies from the available dataset.
- 🎭 **Genre Filtering** — Filter movies by genre.
- ⭐ **Ratings & Insights** — View movie ratings and relevant information.
- 🌙 **Interactive UI** — Clean, dark-themed Streamlit dashboard.

## 🛠️ Tech Stack

- **Language:** Python
- **Frontend:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Similarity Computation:** SciPy / Scikit-learn

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd Movie-Recommendation-System
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## ⚙️ How It Works

The system processes movie data and uses a recommendation algorithm to identify similar movies or relevant recommendations based on user preferences.
